# BeamBench v1.2.0

本版本在保留原版UI、场景和光照的基础上，加入三套可拆装光具库及独立可选的精细模型。源码继续按GPL-3.0-or-later发布，保留上游署名；这是独立衍生版本。

## 主要变化

- 几何光学与高斯光束库新增13项原生参数预设和6个场景，与偏振库独立安装/移除；三库合计20项预设。
- 全部光具、两类光源和公共支架提供精细外观：圆镜座、压圈、旋转刻度、工作面及方向提示等；精细入口与原版入口分开。
- 精细探测器采用单侧感光窗：正面读数并终止光路，背面阻挡无读数；原版继续原有双向、可穿透行为。旧场景在两种页面中的下游光路可能因此不同。
- 精细版偏振片及所有波片操纵杆延伸至原球心，修复杆头分离，保留球头位置与拾取范围。
- 项目约定feedback/用于问题截图；该目录不会随源码提交或Release发布。

## 验证与限制

发布前运行typecheck、lint、309项单元测试、文档检查和四种构建。模型与操纵杆已有原版精确截图、真实拖拽、历史/读档及重复加载资源验证，见docs/builds下对应记录；没有声称完整历史E2E或所有设备性能均已通过。

薄透镜凸凹外形为示意；圆形可见镜片仍沿用原有计算孔径，光栅纹理不是微观沟槽。原生文件加载的历史时序行为未在本版本修复，详见[操纵杆完成记录](../builds/2026-10-24-fix-detailed-ugi-connection.md)。

## 从源码构建

使用Node.js >=20，执行npm ci。原版默认/基础版分别运行npm run build:standalone和npm run build:basic；精细默认/基础版分别运行npm run build:detailed和npm run build:basic:detailed。npm run release生成含四入口、对应源码与清单的ZIP/TAR。
