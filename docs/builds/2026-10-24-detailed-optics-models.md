# 全量光具精细模型完成记录

日期：2026-10-24。关联[实施前计划](../plans/2026-10-24-detailed-optics-models.md)。Process Hub未启用，使用普通项目文档。本次仅本地实施，没有更新GitHub。

## 实际完成

- 覆盖全部10种光具工厂、三个库全部20个预设、两类光源及公共底座/立柱。全量结构审查表、实物结构参考和简化边界见[模型说明](../DETAILED_MODELS.md)。不是只完成透镜、波片和探测器样件。
- 镜片类改为圆形固定架或圆形旋转架，细化压圈、镜座安装脚、锁紧件、刻度数字盘及与轴角同步的指针。薄透镜显示正负曲率示意，厚透镜和曲面镜提供独立圆形曲面与连续侧壁，镜座深度适配厚度。复用原版镜面材质/高光纹理。
- 分束器/PBS采用薄片镜座和偏振参考标记，保持当前平面分束模型；光栅保留方形并区分反/透工作面和沟槽方向提示；挡光器增加哑黑吸收面；法拉第旋光器增加轴向壳体和两端窗口；光源出口与计算轴心对齐并补充机身细节。
- 探测器提供局部−Z侧明确感光窗、深色接收面、不透明背盖和侧接线口。精细版正面产生读数后终止光路，背面/外壳阻挡无读数，重算清除旧读数；结构化追迹同步朝向与吸收处理，新增可选detectorMode=front-absorbing属性。原版网页仍保留双向读数和穿透行为。
- 通过独立模型模块和精细构建专用、唯一锚点校验的适配插件实现，未改写原版上游源文件。原版UI、环境、灯光、桌面、相机、初始摆放及光学算法继续保留；厚透镜/曲面镜的计算表面与可见外观分离。
- 新增两种独立单文件入口：[精细基础版26项](../../dist-basic-detailed/beambench-standalone.html)、[精细默认版30项](../../dist-detailed/beambench-standalone.html)。原来的dist-basic和dist入口已重建，分别仍26/30项且modelProfile=original。新增命令、构建元数据、验证套件、图册工具及发行包配置文件清单；未改变库API 1或ZIP安装方式。
- [全类对照图册](../../artifacts/detailed-models-20261024/gallery/index.html)包含20个样本、100张图片：原版/精细版对照及精细版正、背、侧面。光具对照使用同一相机操作，光源对照使用各自内容适配的侧视图。全部公共支架随样本展示。

## 验证结果

- 23个文件、288项单元测试通过，其中新增29项覆盖全类模型、全部库预设、有限顶点/拾取映射、计算表面身份与坐标不变、参数更新（含PBS偏振方向）、移除释放、世界感光半径、正反面判定、两条传播路径和六个实验示例。
- typecheck（四个构建均执行）、lint、verify:docs及四种单文件构建通过；相关工具node --check通过。Vite仍有现有大bundle提示；插件显式声明不提供转换源映射，精细适配文件没有精确源码行号映射。
- 5项浏览器验收最终全部通过：原版默认构建的精确截图、全类变体图册/旧格式加载、真实拖拽/撤销/重做及两种模型配置恢复、单面探测器与下游终止/清旧值、重复加载资源稳定性。原版截图只统一构建时间文字，未更新原始基准掩盖差异；环境/相机保持一致。
- 原版截图在Playwright打包headless shell执行；功能/图册/资源测试使用独立本机Chrome，未访问用户浏览器资料。沙箱外浏览器启动经工具权限审查获准。
- 原版上游全部源文件逐字节不变；现有12个冻结文件哈希及入口冻结区域仍由原测试通过。额外检查点和四种最终单文件SHA-256见核验清单。
- 10类混合场景的采样平均帧时间和中位数：两版均约16.7ms。观察到的绘制调用每帧423→323。精细版重复清空/加载4轮后几何体172→172、纹理6→6。此为同机headless/vsync条件下的采样，不是GPU吞吐或其他设备上的性能保证；未观察到本次场景帧时间增加超过20%。

## 调试中发现并修复

首轮浏览器4项通过、资源稳定性失败：几何体164→228。补充操作手柄/轮廓释放后仍存在增长（到204），进一步定位到Three.js上传的不可见拾取网格；精细版移除时释放这些每器件独有资源，最终模型稳定为172。图册复核中也修正了锁紧旋钮的连接，增加径向进入套筒的螺杆，避免装饰件悬空。

逐张视图检查还发现镜面背向剔除、厚透镜镜座未覆盖实际深度、刻度盘位于观察背侧；已修复并重新生成全部图册。薄透镜补齐连续侧壁。新增测试脚本曾出现语法/配置和未更新世界矩阵的断言问题，修正后最终全部通过。原版代码和视觉基准均未为这些问题调整。

## 限制与复现

薄透镜焦距不能唯一决定实物曲率，所以外形仅用于凸/凹识别；原生计算孔径和表面仍有理想化近似，安装架不新增传播遮挡。光栅纹理不是微观物理沟槽。精细探测器使旧场景的下游光路有意改变；在原版页面加载同一场景时仍适用原版规则。非均匀缩放下结构化观测使用保守的圆形感光半径，不等同于三维外壳求交。

未运行全部历史E2E、冷安装及其他设备性能测试。原版混合场景的资源增长在本次测量中仍存在（130→246），依照保留原版边界，没有改动原版释放逻辑。没有制作或发布新的GitHub Release。

构建：npm run build:detailed、npm run build:basic:detailed。测试：npm run test:unit:run、npm run test:models:browser；生成图册：node tools/make-model-gallery.mjs。
