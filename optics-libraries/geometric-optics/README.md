# 几何光学库 1.0.0

需要基础实验室1.1.0或更高版本（数据接口API 1）。全部器件使用原版工厂、材质和算法，源包无需安装偏振或高斯库。

将此目录解压到 `optics-libraries/geometric-optics/`，运行 `npm run build:basic`，打开 `dist-basic/beambench-standalone.html`。卸载时移走目录并重新构建；已保存实验仍使用原生类型，可以恢复。按钮前缀“几何·”，焦距名称单位mm。

## 器件与实验

包含+50/+100/−50mm薄透镜、双凸/双凹厚透镜、平面/凹面/凸面镜，共8项。厚透镜R1/R2=±50mm、折射率1.5、厚4mm；曲面镜R=±200mm，正R在原版ABCD约定下为会聚反射面。

使用原有“载入场景”打开examples中的JSON，安装本库不会自动改变初始场景：

- **converging-diverging.json**：两束平行几何光线分别经+50mm与−50mm薄透镜。正透镜应在后方约50mm会聚，负透镜发散，反向延长线约在前方50mm相交。采用近轴模型，边缘光线不代表真实大数值孔径像差。
- **thick-lenses.json**：两束光经双凸/双凹厚透镜，分别会聚/发散。不能把厚透镜前表面作为理想薄透镜主平面；实际焦距与厚度、曲率和折射率共同有关。
- **curved-mirrors.json**：两束光经R=+200mm和−200mm曲面镜，反射后分别会聚/发散。理想近轴反射焦距为R/2；注意入射面与反射传播方向，几何模型仅反射实际打到镜面的光线。

两条比较光路横向相距100mm，选择原版“全景”或“俯视”观察。可选择器件修改参数；不新增面板、控制器样式或默认灯光。
