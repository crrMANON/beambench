# 高斯光束库 1.0.0

需要基础实验室1.1.0或更高版本（数据接口API 1）。独立提供+25/+50/+100/−25mm薄透镜和原版功率计，共5项，不依赖几何光学库。按钮前缀“高斯·”，焦距单位mm。

解压到 `optics-libraries/gaussian-beams/`，运行 `npm run build:basic`，打开 `dist-basic/beambench-standalone.html`。移走目录并重新构建即卸载；已有原生场景仍可恢复。

## 三个实验

通过原有“载入场景”按钮打开examples中的JSON。示例波长530nm、M²=1，坐标/焦距以米保存；安装不改变默认场景。

- **near-collimation.json**：束腰半径50µm，100mm后放+100mm透镜。输出在有限观察距离内近似准直，不是严格的零发散平面波。比较有/无透镜时光束宽度随传播距离的变化，读取原版输出光束参数。
- **keplerian-expander.json**：近似准直入射（束腰半径1mm），+25/+100mm两透镜相距125mm。中间存在实焦点，理想近轴准直倍率约4倍；有限瑞利长度下应使用完整q参数计算，不要求所有位置的光束半径恰为4倍。
- **galilean-expander.json**：同样入射条件，−25/+100mm两透镜相距75mm。理想倍率约4倍，镜间没有实焦点，仍受有限瑞利长度与入射波前影响。

q采用原版约定：自由传播q→q+L，薄透镜1/q' = 1/q − 1/f；光斑半径为1/e²强度半径。若调整波长、束腰或入射位置，需重新计算，而非机械使用焦距比。功率计沿用原版相对功率显示，不代表真实测量仪校准；本库不新增衍射或孔径裁剪模型。
