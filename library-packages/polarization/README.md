# 偏振光学库 1.0.0

适用于 BeamBench 光具库接口 API 1，复用原版器件模型、Jones计算和参数面板。
提供两个偏振片预设、半波片、四分之一波片、45°法拉第旋光器、PBS和原版功率计。

## 安装与卸载

将本目录放到实验室的 `optics-libraries/polarization/`，执行 `npm run build:basic`，
打开 `dist-basic/beambench-standalone.html`。不需要网络加载，也没有新增主题管理界面。
若希望保留原版全部器件，改用 `npm run build:standalone`，打开 `dist/` 内单文件页。

移走安装目录并重新构建即可卸载。之前保存的场景使用原生类型，不依赖本库继续安装。
源码目录与安装目录是独立的；仅下载本源包不会自动启用它。

## 三个示范实验

通过原有“载入场景”按钮打开 `examples/` 中的JSON（原版保存格式）。示例只在明确载入后改变场景；安装本库不会替换默认演示场景、相机或光照。

- **malus.json：马吕斯定律。** 两个偏振片相差45°。功率计读数与相同路径、分析器0°时相比应约为一半；调到90°应接近零。以比例比较，避免把原版功率计的显示单位误当作绝对瓦数。
- **half-wave.json：半波片。** 两片平行偏振片之间的HWP快轴22.5°，预期输出相对入射线偏振转45°。末端分析器0°时，相对无波片路径的强度约一半；扫描分析器应出现最大/最小值。
- **quarter-wave.json：四分之一波片。** QWP快轴45°、相位延迟π/2。线偏振经其成为圆偏振，旋转末端分析器时强度应保持约一半。圆偏振手性取决于原版坐标和相位约定。

保持原版偏振标记开启，可同时观察偏振变化。器件需保持共轴；以原版光源和理想Jones元件为模型，示例不模拟真实器件的色散、制造误差或完整实验室损耗。通用Trace接口不等同于网页Jones偏振传播，实验结论以原生传播路径为准。

## 扩展

复制 `library.json` 结构并使用新的库ID即可创建同接口库。API 1仅接受文档列出的原版工厂和参数，不接受脚本、模型文件或新物理算法。
